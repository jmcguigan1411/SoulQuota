# Soul Quota

Co-op 3D bullet heaven (1-4 players). Death is understaffed: harvest the horde,
carry souls on your back, bank your quota at the lantern before midnight, then
fight the legend that rises.

Unreal Engine 5.8, C++. Everything is placeholder clay shapes (no art assets yet).

## First-time setup
1. Right-click `SoulQuota.uproject` > **Generate Visual Studio project files**.
2. Open `SoulQuota.sln`, set config **Development Editor**, build the `SoulQuota` project.
3. Open `SoulQuota.uproject` (it will say the Graveyard map is missing the first time - that is fine).
4. **Tools > Execute Python Script...** > `Scripts/setup_project.py` (clay material + map lighting). Safe to re-run.
5. Press **Play**.

## Testing co-op on one PC
- Play dropdown > **Number of Players: 2-4**, **Net Mode: Play As Listen Server**.
- Or play alone and add AI teammates: press `~` then `SQAddBot` (repeat for more).

## Controls
| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move / look | WASD / mouse | Sticks |
| Jump | Space | A |
| Dash | Left Shift | RB |
| Pick up / drop a downed teammate's skull | E | X |
| Pick reaper (lobby 1-6) / level-up / buy in shop | 1-6 | D-pad |
| Ready (lobby + shop) | R | Start |
| Change biome / toggle Endless (host, lobby) | B / O | LB / Back |

## Debug console commands (`~`)
| Command | Does |
|---|---|
| `SQAddBot` | Adds an AI reaper |
| `SQSpawn 500` | Spawns 500 enemies (stress test) |
| `SQSkip` | Skips the current phase (night -> midnight, kills boss, ends shop) |
| `SQSouls 50` / `SQXP 50` | Gives souls / team XP |
| `SQGod` | Toggle invincibility |
| `SQReaper Mort` | Switch reaper (Grim, Mort, Widow, Bonesmith) |
| `SQReload` | Reload all CSV data |
| `SQStats` | Toggle the FPS / enemy count line |
| `SQHost` / `SQJoin 192.168.x.x` | LAN host / join |
| `stat net` / `stat unit` | Engine network / frame stats |

## Changing the game without recompiling
All numbers live in `Content/Data/*.csv` (open in Excel). Edit, save, press Play again.
- `Tuning.csv` - night length, quotas, spawn rates, arena size, enemy cap
- `Reapers.csv` - playable characters
- `Upgrades.csv` - weapons, relics, evolutions
- `Enemies.csv`, `Bosses.csv`, `Biomes.csv`, `Bonds.csv`, `Shop.csv`, `Story.csv`
- Testing: set `UnlockAllReapers` / `UnlockAllBiomes` to 1 and `NightSeconds` to 60 in Tuning.csv
